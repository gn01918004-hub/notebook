# 測量入口網

給新進同仁和臨時需要查資料的人使用：依業務查**文件、作業步驟、注意事項、收費**，並連到相關法規、函釋和其他小工具。

## 怎麼用

1. 把整個 `測量入口網` 資料夾複製到電腦或共用資料夾（兩個檔案要放在一起）。
2. 用瀏覽器（Chrome / Edge）打開 `首頁.html`。
3. 從左側選業務，或在上方搜尋框輸入關鍵字（例如：協界、退費、0.25公頃）。

不需要網路，也不需要安裝任何東西。每頁都可以按「列印」印出來給新人。

## 怎麼新增或修改內容

**只要改 `data.js`**（用記事本或 VS Code 打開），存檔後重新整理網頁就會更新。檔案分成四段：

| 區塊 | 內容 |
|---|---|
| `小工具` | 你其他小工具的捷徑：名稱、說明、連結（網址或 `file:///D:/...` 路徑） |
| `共同注意` | 每個業務頁最下面都會顯示的提醒 |
| `法規函釋` | 法規條文和函釋，各業務用 `法規: ['id']` 引用 |
| `業務` | 各項業務的簡介、文件、步驟、注意事項、收費 |

沒填的欄位會顯示「尚未整理」，可以慢慢補。最簡單的方法是複製一個現有的業務區塊，再修改文字。

修改前建議先備份一份 `data.js`。改完如果畫面變成空白，通常是少了逗號或引號，按 F12 可以看到錯在第幾行。
