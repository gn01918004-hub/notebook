# 測量入口網

給新進同仁和臨時需要查資料的人使用：依業務查**文件、作業步驟、注意事項、收費**，並連到相關法規、函釋和其他小工具。

網站檔案在 `docs/` 資料夾，由 GitHub Pages 發布成網頁：

| 檔案 | 內容 |
|---|---|
| `docs/index.html` | 網頁版面與功能（平常不用改） |
| `docs/data.js` | 所有內容：業務、收費、法規函釋、小工具捷徑 |

## 怎麼更新內容

請 Claude 修改 `docs/data.js`，例如：「幫我在分割加一則函釋：……」。
修改合併到預設分支後，約 1～2 分鐘網站就會更新（瀏覽器可能要按 Ctrl+F5 強制重新整理）。

也可以直接在 GitHub 網頁上打開 `docs/data.js`，按鉛筆圖示編輯後存檔。

## 注意

GitHub Pages 發布的網頁**任何知道網址的人都看得到**（即使 repo 設為私人也一樣）。
法規、函釋、收費標準都是公開資訊，沒有問題；但請不要放入個資（地主姓名、身分證號）或不宜公開的內部資料。

## 離線使用

把 `docs` 資料夾整個複製到電腦，直接打開 `index.html` 也能用。
