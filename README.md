# 測量製圖知識庫

給新進同仁和臨時要查資料的人使用的內部知識庫，範圍包括：

- **法規**：土地法、農業發展條例、地籍測量實施規則、農舍相關規定等
- **函釋**：上述法規的解釋令和函示，每份都要標記是否仍有效
- **作業流程**：鑑界、分割、建物第一次測量及所有權第一次登記（保登）、新登記等
- **經驗筆記**：資深同仁的實務經驗、踩過的坑、案例
- **常見問答**：新人最常問的問題

## 設計原則：低維護

沒有專人維護，所以這套做法刻意簡化：

1. **資料都是 Markdown 純文字檔**，用記事本或任何編輯器都能修改，不綁定特定軟體。
2. **問答功能交給現成服務**（建議用 NotebookLM，見下方），不用架伺服器，也沒有系統要更新。
3. **每份資料一個檔案、照固定範本寫**，誰來補充都寫得一樣。

## 資料夾結構

```
範本/                 ← 新增資料時複製這裡的範本
知識庫/
  01_法規/            ← 法規全文或重點條文（從全國法規資料庫下載）
  02_函釋/            ← 一則函釋一個檔，用「函釋卡範本」
  03_作業流程/        ← 一種業務一個檔，用「作業流程範本」
  04_經驗筆記/        ← 實務經驗、案例，用「經驗筆記範本」
  05_常見問答/        ← 新人常見問題
工具/
  合併來源檔.py       ← 把各資料夾合併成少數幾個大檔，方便上傳 NotebookLM
  AI回答規則.md       ← 貼到 NotebookLM 或 Claude 的回答規則
建置步驟.md           ← 從零開始的完整步驟（先看這份）
```
